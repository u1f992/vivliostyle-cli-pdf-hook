# @u1f992/vivliostyle-cli-pdf-hook

A proxy package for [puppeteer-core](https://github.com/puppeteer/puppeteer/tree/main/packages/puppeteer-core), designed to provide hooks for PDF output processing in the [Vivliostyle CLI](https://github.com/vivliostyle/vivliostyle-cli).

Compatible with Vivliostyle CLI [v10.3.0](https://github.com/vivliostyle/vivliostyle-cli/releases/tag/v10.3.0), which ships with puppeteer-core [v24.27.0](https://github.com/puppeteer/puppeteer/releases/tag/puppeteer-core-v24.27.0).
